# Genie

> Genie is an open source, full-stack web framework for the Julia programming language, built by the Barcelona-based company Genie (backed by Speedinvest). It lets data scientists and R&D engineers turn Julia models, simulations, and analyses into production-ready, data-centric web apps, REST APIs, and interactive dashboards. Core components: Genie.jl (backend + APIs), Stipple.jl (low-code reactive UIs), and SearchLight.jl (database ORM), plus first-party auth plugins and Genie Builder (a VS Code drag-and-drop UI builder with AI assistant). MIT-licensed, distributed via the Julia General registry.
